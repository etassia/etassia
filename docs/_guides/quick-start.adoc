= Quick Start Guide

This guide will help you create your first diagram with Sirena in 5 minutes.

== Prerequisites

Ensure Sirena is installed. If not, see the link:../installation/[Installation Guide].

== Your First Diagram

=== Step 1: Create a Mermaid File

Create a file named `my-first-diagram.mmd`:

[source,mermaid]
----
graph TD
    A[Start] --> B{Decision}
    B -->|Yes| C[Process]
    B -->|No| D[End]
    C --> D
----

=== Step 2: Render to SVG

Run Sirena to generate an SVG:

[source,shell]
----
etassia render my-first-diagram.mmd -o output.svg
----

=== Step 3: View the Result

Open `output.svg` in your browser or image viewer to see your flowchart!

== Common Diagram Types

=== Flowchart

[source,mermaid]
----
graph LR
    A[Input] --> B[Process]
    B --> C[Output]
----

=== Sequence Diagram

[source,mermaid]
----
sequenceDiagram
    Alice->>Bob: Hello
    Bob-->>Alice: Hi there!
----

=== Entity-Relationship Diagram

[source,mermaid]
----
erDiagram
    CUSTOMER ||--o{ ORDER : places
    ORDER ||--|{ LINE_ITEM : contains
----

== Programmatic Usage

Use Sirena in your Ruby code:

[source,ruby]
----
require 'etassia'

# Render from a string
mermaid_code = <<~MERMAID
  graph TD
    A --> B
MERMAID

svg = Etassia.render(mermaid_code)
File.write('output.svg', svg)

# Render from a file
svg = Etassia.render(File.read('diagram.mmd'))
----

== Batch Processing

Render multiple diagrams at once:

[source,shell]
----
etassia batch -i diagrams/ -o output/
----

This renders all `.mmd` files in `diagrams/` directory to SVG files in `output/`.
