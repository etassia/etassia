= Installation Guide

== Requirements

Etassia requires:

* Ruby 3.2 or higher
* Bundler (for development)

== Installation Methods

=== Via RubyGems (Recommended)

Install Etassia directly from RubyGems:

[source,shell]
----
gem install etassia
----

=== Via Bundler

Add Etassia to your `Gemfile`:

[source,ruby]
----
gem 'etassia'
----

Then install:

[source,shell]
----
bundle install
----

=== From Source

Clone the repository and install locally:

[source,shell]
----
git clone https://github.com/claricle/etassia.git
cd etassia
bundle install
bundle exec rake install
----

== Verification

Verify the installation:

[source,shell]
----
etassia version
----

You should see output similar to:

----
etassia version 0.1.0
----

== Troubleshooting

=== Command Not Found

If `etassia` command is not found after installation, ensure your gem bin directory is in your PATH:

[source,shell]
----
echo 'export PATH="$HOME/.gem/ruby/X.X.0/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
----

Replace `X.X.0` with your Ruby version.

=== Permission Errors

If you encounter permission errors during installation, try:

[source,shell]
----
gem install etassia --user-install
----

Or use a Ruby version manager like `rbenv` or `rvm`.
